# 游鉴 · GameLens

**看懂数据，选对游戏。**

一款面向 Steam 玩家的游戏发现与决策工具，通过价格、类型、语言和口碑等多维数据，帮助你找到值得玩的游戏。提供可直接打开的单文件 HTML，以及可选的 Python 本机数据服务。

> **先看数据标识：内置 36 款为模拟样例，不是实时行情。** 除游戏名称 / AppID 用于示范导航外，价格、评分、语言、类型、平台、日期等示例属性均未经当前核实。联网采集库、演示库和导入库相互隔离。本轮仅完成文首列出的真实联网抽样；不能把离线测试理解为所有 Steam 数据已验证。

## 1. 直接使用 HTML

打开 `steam_lens.html`，即可使用演示数据进行筛选、排序、统计、对比和导出，不需要安装依赖。页面的“导入”支持本工具格式的 JSON。筛选和计算不依赖外部字体、JavaScript 库或网络；默认封面图片来自 Steam CDN，失败时显示明确标识的排版占位封面。在页脚“显示设置”中关闭封面，可避免这类外部图片请求。

HTML 里的“联网获取”不是伪造的刷新按钮：直接打开文件时会给出本机服务启动说明，不会宣称已刷新真实价格。

## 2. 获取真实 Steam 数据

需要本机安装 **Python 3.10 或更新版本**。运行时只使用标准库，**不需要 pip install**，也不索取 Steam 账号、Cookie 或 API Key。

### Windows

解压整个目录，双击 `start_windows.bat`，保留命令窗口。也可以在该目录的终端运行：

```powershell
py -3 server.py
```

只有 `python` 命令可用时：

```powershell
python server.py
```

### macOS / Linux

在解压目录打开终端：

```bash
python3 server.py
```

也提供 `start_mac.command` 和 `start_linux.sh`。文件没有执行权限时可从终端运行 `bash start_mac.command`，无需降低系统安全设置。

服务启动后会尝试打开：

```text
http://127.0.0.1:8765
```

请在**这个本机地址对应的页面**点击“联网获取”，选择地区，通过名称搜索、热销 / 特惠 / 新发售发现，或直接输入 Steam AppID / 商店链接添加游戏。例如：

```text
413150, 105600, 1145360, 427520, 1366540
```

这些 ID 只是输入示例，不意味着已经获取了它们的真实报价。搜索每页最多 20 个候选；可继续下一页。单次任务最多 200 个 AppID，逐个获取，可取消。成功与失败分别记录，已有采集结果不会因为另一款失败被清空。后端仅接受游戏本体，跳过 DLC、试玩和软件。

关闭服务：在命令窗口按 `Ctrl+C`。端口占用时：

```bash
python server.py --port 8766
```

不自动打开浏览器：

```bash
python server.py --no-browser
```

服务就绪仅代表本机程序运行，不代表 Steam 上游可访问。若提示 DNS、连接超时、403、429 或搜索结构变化，请以具体错误为准；未提供绕过验证或公共代理方案。名称搜索不可用时，可以尝试直接输入 AppID，但也不保证详情接口可用。

## 3. 已实现功能

| 维度 | 支持内容 |
| --- | --- |
| 价格 | 最低 / 最高预算、免费 / 付费、仅折扣、现价、原价、减价比例；缺失报价保持未知 |
| 地区 | 国区 CNY、港区 HKD、美区 USD、日区 JPY；每个地区独立游戏池，不混算，不伪造汇率换算报价 |
| 类型 | 商店类型多选，组内满足任一；不同筛选维度共同生效；不会把 genres 冒充社区标签 |
| 语言 | 简体 / 繁体 / 任意中文、英语、日语、韩语等；中文完整音频单独过滤 |
| 评分 | 正面评价占比、正面 / 负面 / 总评论数、最小 / 最大样本量、95% Wilson 下界、Metacritic（有值时） |
| 平台与玩法 | Windows / macOS / Linux、单人、合作、多人、完整手柄、云存档、抢先体验、发行年份 |
| 详情 | 开发商、发行商、发行日期、最低 / 推荐配置原始文字、各字段来源与采集时间 |
| 排序 | 综合推荐、Wilson、好评率、评论数、价格升 / 降序、折扣、发行时间、Metacritic，共 9 种 |
| 快捷方案 | 中文性价比、高分优先、一起开黑、小众宝藏、Mac 可玩；均为可查看的规则筛选 |
| 对比 | 同地区最多 4 款横向对比；来源与模拟提示不会隐藏 |
| 收藏 | 本浏览器本地收藏，不修改 Steam 愿望单 |
| 统计 | 价格中位数、按评论数加权好评率、折扣数量；6 个图表 / 覆盖率面板，随筛选更新 |
| 导出 | CSV 导出全部筛选并排序后的结果，不限当前页；JSON 导出当前地区完整已加载库和收藏 ID |

好评率口径采用官方评论接口的 `query_summary`，请求全部语言、Steam 购买、过滤跑题活动的汇总。不是近 30 天的好评率，也不包含全部来源评论。`day_range` 不是“近期好评率”开关。详情面板及导出保留具体口径。

语言汇总只表示商店标注支持哪些语言及是否完整音频，不单独保证中文界面 / 中文字幕覆盖。macOS 商店标记也不保证新版系统或 Apple Silicon 实际兼容。购买前仍需核对商店语言表、系统要求和结算价格。

## 4. 推荐分如何计算

默认权重：

```text
工具推荐分 = 65% × 置信口碑
           + 20% × 预算友好
           + 10% × 折扣力度
           +  5% × 中文支持
```

- **置信口碑**：正面评论比例的 95% Wilson 下界，再乘 100。小样本的 100% 好评不会简单胜过大量评论下的高好评率。它不是刷评检测或评测质量保证。
- **预算友好**：`clamp(100 × [1 − ln(1 + 现价) / ln(1 + 参考上限)], 0, 100)`。参考上限优先使用你填写的最高预算；未填写时按地区使用 CNY 200 / HKD 240 / USD 40 / JPY 5000。这是可解释的设计参数，不是市场统计。
- **折扣力度**：商店返回的减价百分比；高折扣不等于历史最低价。
- **中文支持**：商店标注简体或繁体中文为 100，否则为 0；缺少语言数据则未知。

四项权重可调整，按总和归一化，不能全部为零。任一非零权重需要的字段缺失，综合分保持未知并排在数值后面；将某项权重设为零后，该项缺失不会阻止计算。零评论不等于 0% 好评，也不产生 Wilson 分。免费价格为零只在明确免费时成立，未知报价绝不当作免费。

这是本工具的规则推荐分，不是 Steam 官方评分，不包含模型推断的个人口味，也不是作者实际游玩结论。排序和统计只覆盖当前已加载、已筛选的游戏。

## 5. JSON 格式与数据处理

`demo_data.json` 提供完整结构示例，字段单位：**主货币单位**，例如 CNY 的 `price: 48` 表示 48 元，不是 48 分。不要将 Steam 原始分单位直接导入。币种必须与地区对应。

```json
{
  "schemaVersion": 1,
  "kind": "steam-lens-export",
  "mode": "import",
  "region": "cn",
  "currency": "CNY",
  "favorites": [],
  "games": [
    {
      "appid": 413150,
      "name": "待补充数据的示例条目",
      "region": "cn",
      "currency": "CNY",
      "price": null,
      "originalPrice": null,
      "discount": null,
      "isFree": false,
      "genres": [],
      "languages": null,
      "audioLanguages": null,
      "reviews": null,
      "source": "imported",
      "detailsAt": null,
      "reviewsAt": null
    }
  ]
}
```

完整格式可用页面 JSON 导出获得。单文件最大 20 MB，单次最多导入 5,000 条；同一导入文件不能重复“地区 + AppID”。先验证整批，再确认合并，不会半批写入。评论存在时要求正面 + 负面 = 总评论数。导入文件自称 `steam` 也会转成“导入 · 未验证”；演示来源会保留。导入库不覆盖真实采集库。

收藏、偏好、采集库保存在当前浏览器 localStorage。不同浏览器、不同端口、文件打开与本机服务地址之间，存储不一定共享。空间不足或禁止存储时给出提醒，当前会话继续工作；建议定期导出 JSON。导出的 CSV 会保留来源、地区、采集时间，UTF-8 BOM 便于表格软件识别，并处理以公式字符开头的文本。

## 6. 本机服务与访问边界

服务只监听 `127.0.0.1`，校验 Host / Origin / 请求标识，只向固定的 Steam 商店域名发出只读请求，不接受任意目标 URL。没有登录、发信、下单、修改账号或写入远程愿望单的功能。

上游请求全局串行，间隔至少 1.6 秒；设超时和响应大小上限。5xx 最多重试一次；429 进入冷却并遵守 Retry-After，不绕过限流。缓存按完整 URL 区分地区：详情 1 小时、评论 6 小时、搜索 15 分钟。缓存文件为 `.steam_lens_cache.sqlite3`。更新失败而使用旧缓存时保留原采集时间并显示警告，不伪装为刚刚获取。

本机服务不是可直接对公网部署的多用户平台。当前页面面向个人选购的局部游戏池，不是全 Steam 数据仓库。没有常驻后台扫描、定时价格提醒或海量自动爬取。

## 7. 已知未接入项

没有真实历史最低价、跨商店比价、实时在线人数、近期好评率、游玩 / 通关时长、Steam Deck 认证、自动个人账号库分析。没有这些字段时不会编造估计值，也不把它们纳入推荐分。地区选择不是账号改区，且不保证该地区商品实际可购买。

Storefront 的详情和搜索端点属于非正式公开文档接口，可能改变或暂不可用。本包已验证本地逻辑与模拟上游合同，但制作环境无法连接真实 Steam，上游可用性须在你的本机网络实测。测试详情见 `TEST_REPORT.md`。
