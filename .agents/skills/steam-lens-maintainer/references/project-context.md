# 项目交接与范围

## 用户目标

做一个中文 Steam 游戏分类、统计、排序与推荐工具，围绕价格、游戏类型、语言、评分及其他实用条件筛选游戏，提供可操作 HTML。随后用户反馈“部分游戏封面显示异常”，已交付 v1.1 封面修复版。本次要求把已有成果整理成 Skill，交由 Codex 继续优化。

没有指定下一轮必须迁移框架或增加收费 API。默认先保证现有版本可靠，再按用户新任务增量修改。

## 交接基线

- 来源：本次会话提供的 `steam_lens_fixed_full.zip`，不是初版 `steam_lens_full.zip`。
- 应用版本：v1.1 封面修复版；本地 API health 中 `version: 1` 是现有返回值，不代表封面修复未应用。
- 原始源码压缩包保存在 `assets/steam-lens-v1.1-baseline.zip`（相对本 Skill 根目录）。校验清单见同目录 `baseline-manifest.json`。
- Skill 接手包不修改原应用的业务代码。原包的 18 个文件保持原字节；新增 Skill、接手说明与校验材料。
- 原 `TEST_REPORT.md` 及测试结果 JSON 是历史报告；本次重新执行的结果另记 `handoff-verification.md`，以后不能把它们当作新运行结果。

## 当前实现

无前端依赖的 HTML/CSS/JavaScript；本机 Python 3.10+ 标准库服务可选。直接打开 HTML 能用演示数据或导入数据；获取真实 Steam 数据要运行配套服务。

已有价格/折扣/预算、地区、类型、语言、中文配音、好评率与评论数、Wilson 口碑校正、平台与玩法筛选、9 种排序、统计图表、卡片/表格、详情、最多 4 款对比、本地收藏和 JSON/CSV 数据往返。实际函数以当前工作区代码为准。

## 最近封面修复已做的事

保存完整 `headerImage/capsuleImage/capsuleImageV5`；同 AppID 的 Steam 图片地址校验；官方地址优先、受限 CDN 候选；懒加载、超时、迟到响应隔离、短期失败记忆、成功源复用、重试；卡片和详情等比完整显示，窄屏单列。

这些是代码和离线测试覆盖范围，不是每款真实游戏资源可达性的保证。

## 必须明确的限制

内置 36 款用于演示，价格、评分、语言等不是当前真实行情。初版及封面修复版均未完成真实 Steam 详情/评论/CDN 端到端验证。本次 Skill 打包也没有完成真实联网验证。

“全方面统计”目前指已加载游戏池的多维统计，不是已采集整个 Steam 全库。历史最低价、跨商店比价、实时在线、近期好评率、通关时间、Steam Deck 验证与账号库分析尚未接入，不要显示伪造结果。

## 工作区保护

用户已有项目时，以它为工作对象，先查看版本和未提交改动。`assets` 是恢复基线，不是每次开始都要复制的模板。不能用初始化动作回滚用户代码、收藏或缓存。
