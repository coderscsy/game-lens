# 首次接手任务

此文件在用户只要求“继续优化”而没有更具体任务时使用；新的明确任务优先。

## 默认本轮目标

接手当前 Steam Lens 项目，核对 v1.1 封面修复链路，复现并修复明确缺陷，保证原有筛选、推荐、统计与收藏不回退。不把本轮变成从零重建。

## 执行顺序

1. 确认项目目录、源码版本和未提交修改，阅读 Skill 与交接说明。
2. 构建当前源码并运行能执行的基线测试，报告缺依赖或原有失败。
3. 优先检查封面完整 URL 的保留、候选顺序、同 AppID 校验、超时、重试、旧请求隔离和窄屏比例。已有具体问题 AppID 时优先复现它。
4. 网络可访问时，做少量真实详情/评论/CDN 抽样；无权限或网络不通时停止该验证路径，保留离线结果，不断言所有真实封面正常。
5. 有确定问题就补最小回归并修复；没有确定问题则输出证据和待验证项，不制造无意义重构。
6. 重新生成 HTML、运行受影响回归、提供代码修改与测试摘要。

## 本轮不自动加入

账号登录、愿望单同步、订阅价格提醒、跨商店比价、全 Steam 后台爬取、Steam Deck 数据、游戏时长、框架迁移、付费 API。这些可作为后续明确授权的独立任务，不是修封面的前提。
